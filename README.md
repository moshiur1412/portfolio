# MD. Moshiur Rahman — Portfolio

Modern static portfolio website built with HTML, CSS &amp; JavaScript. Ready to publish on GitHub Pages.

## Deploy to GitHub Pages

1. Push this repo to GitHub (`moshiur1412/portfolio`)
2. Go to **Settings → Pages**
3. Under "Source", select **Deploy from a branch**
4. Choose `main` / `master` branch and `/ (root)` folder
5. Click **Save**

Your site will be live at `https://moshiur1412.github.io/portfolio`

## PDF Download

Open the site in your browser and click **Download PDF (Print)** — the print stylesheet will render a clean resume-ready layout. Save as PDF from the browser print dialog.
